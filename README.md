# Cary-GIS-Analysis
Analysis of subdivisions and their location to closest school as well as the amount burglaries that have occurred for each residential subdivision. Data was gathered from county website and using python modules such as geopandas, pandas and folium aided in aggregated the data to provide visual and quantative data for viewing.


Burglary Map shows each subdivision and the number of burglaries that have occurred in each on over a couple year period:
Link to burglary analysis map:
https://jcampos919.github.io/Cary-GIS-Analysis/burglary_map.html


School proximity map shows map of all Cary schools and its visual relation to each subdivision in Cary.
Link to school proximity analysis map:
https://jcampos919.github.io/Cary-GIS-Analysis/School_proximity.html


Created shapefile of burglary points by merging together burglary reports and the subdivision they occurred in with the city residential subdivision data. OSM map created here: https://jcampos919.github.io/Cary-GIS-Analysis/burglary_points_map.html
